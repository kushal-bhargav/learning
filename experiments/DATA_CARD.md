# GMGI GAN Dataset Card

## Status

This data card is regenerated by `src.gan.data_pipeline` for the current GMGI greeting-card dataset path. The active source is `gauravs101/synthetic-greeting-cards` from Hugging Face Datasets.

## Source Selection

- Source: `gauravs101/synthetic-greeting-cards`
- Loader: `datasets.load_dataset("gauravs101/synthetic-greeting-cards")`
- Current assumption: image-only rows; captions, occasion labels, and relationship labels are optional and may be absent.
- License: verify the Hugging Face dataset README/card before publication or redistribution.

## Intended Use

The dataset is used as a first gifting-aligned visual source for training the GMGI conditional GAN on greeting-card imagery. It replaces the earlier broad art-image source path.

## Processing

1. Load greeting-card images from Hugging Face Datasets.
2. Reject rows without decodable image bytes or configured minimum dimensions.
3. Preserve raw images with SHA-256 checksums.
4. Convert to RGB, square-crop or square-pad according to config, resize with Lanczos, and save PNG files.
5. Encode processed images with OpenCLIP.
6. Cluster normalized CLIP embeddings with deterministic k-means++.
7. Map clusters to weak emotion labels using CLIP text prompts.
8. Create a deterministic cluster-stratified train/validation split.
9. Write JSONL metadata, NumPy embeddings, rejection logs, run report, and contact sheet.

## Limitations

This source is image-only, so any `description` used during training is a generic fallback unless future datasets provide captions/prompts. Relationship and occasion conditioning remain weak until additional labeled gifting datasets are introduced.
